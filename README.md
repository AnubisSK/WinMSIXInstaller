# WinMSIXInstaller

**WinMSIXInstaller** is a fast and lightweight utility designed to simplify the installation of `.msix` and `.appx` packages on Windows 10 and Windows 11 operating systems.

This application is specifically tailored for users of **LTSC (Long-Term Servicing Channel)** editions. Since these Windows versions do not natively include the Microsoft Store or the pre-installed Windows App Installer, installing modern packages usually requires manual work via PowerShell. WinMSIXInstaller fully automates this process and brings a user-friendly solution.

## 🚀 Key Features
* **Full LTSC Support:** Works flawlessly on both Windows 10 LTSC and Windows 11 LTSC.
* **No Store Dependencies:** Requires no Microsoft Store components or any other background bloatware.
* **Simple & Fast:** Straightforward installation process for `.msix` and `.appx` files.
* **Standalone Application:** Ready to use out of the box without complex configuration.

## 📥 Installation & Usage

Since this repository is used primarily for distribution, the source code is kept private. You can download the compiled application directly from the Releases tab.

1. Navigate to the **[Releases](../../releases)** section on the right side of this repository.
2. Download the latest compiled version of `WinMSIXInstaller.exe` (or the provided archive).
3. Run the application.
4. Select the desired `.msix` or `.appx` file you wish to install and follow the on-screen instructions.

## 💻 Compatibility
* Windows 10 LTSC (all modern builds)
* Windows 11 LTSC
* Traditional Windows 10 / 11 editions (Pro, Home, Enterprise)
